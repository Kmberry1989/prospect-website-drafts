# Owner Guide — B&K Rootbeer

## What you can edit yourself
- **Business info** — name, tagline, phone number, address
- **Announcement banner** — seasonal notes, closures, events, anything urgent at the top of the page
- **Specials** — daily/weekly specials and featured items
- **Menu** — sections, item names, descriptions, and prices
- **Hours** — add, remove, or change any hours row

## How to edit
The live site has a shared admin page at **/admin/**. Kyle sets it up for you with a password and an access token. You sign in, edit the fields in plain English, and the site updates immediately — no coding, no rebuild, no waiting.
